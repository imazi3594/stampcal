# 英傑大戦 速查

對戰時查對手武將計略時長（C）同效果值。繁中對照。

**網址：** [https://imazi3594.github.io/ek-scout/](https://imazi3594.github.io/ek-scout/)

手機瀏覽器打開即可，最近查看會記喺部機度。

## 第一次開網頁（只需一次）

1. 打開 [Pages 設定](https://github.com/imazi3594/ek-scout/settings/pages)
2. **Source** 揀 **Deploy from a branch**
3. Branch 揀 **main**，Folder 揀 **/docs**
4. 撳 **Save**

等一兩分鐘再開上面個網址。之後都係同一個連結。

資料來源：[英傑大戦データベース](https://eiketsudb.com/)
